# FinD Lab @ ICT, CAS

> Financial Intelligence & Data Mining Lab

We are the **Financial Intelligence & Data Mining Lab (FinD)** at the [State Key Laboratory of AI Safety](https://klais.ict.ac.cn/), [Institute of Computing Technology](http://www.ict.ac.cn/), Chinese Academy of Sciences (ICT, CAS).

We study reliable and practical artificial intelligence, with a focus on data mining, graph learning, financial intelligence, large language models, and personalized information processing.

## 🔬 Research Areas

- **Financial Intelligence & Quantitative Research**  
  Reinforcement learning, symbolic regression, formulaic alpha discovery, and AI-assisted quantitative research.

- **Graph Learning, Robustness & AI Safety**  
  Robust graph learning, adversarial attacks and defenses, graph model security, and graph representation learning.

- **Large Language Models for AI Research**  
  LLM-assisted data engineering, model design, optimization, evaluation, and automated research workflows.

- **Personalized NLP & Information Generation**  
  Personalized headline generation, recommendation, summarization, and user-interest modeling.

## 🚀 Featured Open-Source Projects

| Project | Description |
|---|---|
| [AlphaGen](https://github.com/ICT-FinD-Lab/alphagen) | Reinforcement-learning-based generation of synergistic formulaic alpha collections. |
| [Awesome Robust Graph Learning](https://github.com/ICT-FinD-Lab/awesome-robust-graph-learning) | A curated collection of papers, benchmarks, datasets, tutorials, and toolkits for robust graph learning. |
| [Awesome LLMs for AI Research](https://github.com/ICT-FinD-Lab/Awesome-LLMs-for-AI-Research) | Resources accompanying the AI4AIR survey on using LLMs throughout the AI research lifecycle. |
| [SPEAR](https://github.com/ICT-FinD-Lab/SPEAR) | Source code for the WWW 2025 work on structure-preserving graph backdoor attacks. |
| [GRASP](https://github.com/ICT-FinD-Lab/GRASP) | Source code for the KDD 2025 work on graph-agnostic linear transformers. |
| [GrAP3](https://github.com/ICT-FinD-Lab/GrAP3) | A data-free model extraction attack framework under graph pre-training and prompt learning. |
